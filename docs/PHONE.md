# 갤럭시 폰 안에서만 돌리기

컴퓨터도 서버도 없이 **폰 하나로** 전부 돌립니다.
가입할 것도, 카드도, 비용도 없습니다.

> 아이폰에서는 안 되고 **갤럭시(안드로이드)에서만** 됩니다.

---

## 설치할 앱은 2개입니다

| 앱 | 역할 |
|---|---|
| **Termux** | 폰 안에서 프로그램을 돌리는 도구 |
| **Termux:API** | 알림을 띄우고, 자동 수집을 예약하는 데 필요 |

> 안드로이드는 보안상 한 앱이 다른 앱의 알림 권한을 대신 가질 수 없어서 2개로 나뉘어 있습니다.
> 이 2개만 설치하면 됩니다.

⚠️ **플레이스토어의 Termux 는 쓰지 마세요.** 업데이트가 멈춰 있어 동작하지 않습니다.

---

## 0. 폰에 얼마나 부담이 되나 (실측)

| 항목 | 1회 수집 | 하루 (1시간마다) |
|---|---|---|
| **CPU 시간** | 0.25초 | **약 6초** |
| **데이터** | 약 30KB | **약 0.8MB** |

> 하루 종일 돌려도 데이터는 **유튜브 5초 분량**입니다.

| 항목 | 내용 |
|---|---|
| 메모리 | 70MB — **화면을 볼 때만** |
| 저장공간 | 설치에 약 1GB, 데이터는 연 2~3MB |
| 배터리 | 하루 1~2% 수준으로 예상 |
| 데이터 보관 | 전부 폰 안에. **폰을 초기화하면 사라집니다** |
| 제약 | 폰이 꺼져 있는 동안은 수집이 멈춥니다 |

앱을 24시간 띄워두지 않습니다. **안드로이드가 1시간에 한 번 깨워서** 몇 초 일하고 다시 재웁니다.

## 1. 앱 2개 설치 (폰)

폰 브라우저에서 아래 두 곳에 들어가, 각각 **최신 릴리스의 `arm64-v8a` APK** 를 받아 설치합니다.

>
> ⚠️ **두 개를 반드시 같은 곳(GitHub)에서** 받아야 합니다.
> 하나는 F-Droid, 하나는 GitHub 에서 받으면 서로 인식하지 못합니다.
> (F-Droid 를 이미 쓰신다면 둘 다 F-Droid 에서 받으셔도 됩니다)

## 3. 폰에서 설치 — 명령 두 줄

Termux 앱을 열고 아래를 **복사해서 붙여넣기** 하면 됩니다.
(Termux 화면을 길게 누르면 '붙여넣기' 가 나옵니다)

**첫 줄** — 파일을 읽을 수 있게 허락 (팝업이 뜨면 '허용')

```bash
termux-setup-storage
```

**둘째 줄** — 설치 시작

```bash
bash $(find ~/storage -name biotrial-install.sh | head -1)
```

> 압축을 풀 필요도, 폴더를 찾을 필요도 없습니다. 파일이 어디에 저장됐든 알아서 찾습니다.
>
> **15~25분 걸립니다.** 화면이 멈춘 것처럼 보여도 기다려 주세요.
> 중간에 끊겼으면 **둘째 줄만 다시** 실행하면 이어서 진행됩니다.

끝나면 다음 화면이 나옵니다.

```
═════════════════════════════════════════════

  설치가 끝났습니다

  이제 폰 브라우저 주소창에 이렇게 입력하세요

        localhost:8000

  그다음 메뉴(⋮) → 현재 페이지 추가 → 홈 화면

═════════════════════════════════════════════
```

## 4. ⚠️ 배터리 설정 — 이걸 안 하면 멈춥니다

삼성 폰은 배터리를 아끼려고 앱을 강제 종료합니다. **가장 중요한 단계입니다.**

**설정 → 배터리 → 백그라운드 사용량 제한**
→ **절전 앱 / 딥 슬리핑 앱** 목록에 **Termux** 가 있으면 **빼주세요**

**설정 → 애플리케이션 → Termux → 배터리 → `제한 없음`**

## 평소 사용법

**아무것도 안 하셔도 됩니다.**
1시간마다 저절로 확인하고, 새 소식이 있으면 배너 알림이 뜹니다.
폰을 껐다 켜도 그대로 유지됩니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 보기 | 홈 화면의 🧪 아이콘 |
| **뭔가 이상할 때** | Termux 에서 **`bash ~/biotrial/fix.sh`** |
| 지금 바로 확인 | `bash ~/biotrial/collect.sh` |
| 기록 보기 | `tail -30 ~/biotrial/run.log` |

> **외울 명령은 `fix.sh` 하나면 됩니다.**
> 자동 수집이 꺼졌는지, 알림이 되는지, 화면이 켜져 있는지 확인해서 알아서 고칩니다.
>
> 화면이 안 열리면 Termux 앱을 한 번 열어만 봐도 됩니다. 여는 순간 자동으로 켜집니다.

## 잘 안 될 때

### 대부분은 이것 하나로 해결됩니다

```bash
bash ~/biotrial/fix.sh
```

자동 수집·알림·화면을 차례로 확인해서 꺼져 있으면 다시 켭니다.
그래도 이상하면 **그 화면을 그대로 찍어서** 보여주시면 됩니다.

| 증상 | 해결 |
|---|---|
| 몇 분 뒤 저절로 꺼짐 | **4번 배터리 설정**을 안 하신 경우입니다 |
| 설치 중 멈춤 | 와이파이 확인 후 둘째 줄을 다시 실행하세요. 이어서 진행됩니다 |
| 파일을 못 찾는다고 나옴 | 카톡에서 파일을 한 번 눌러 다운로드했는지 확인하세요 |
| 화면이 안 열림 | Termux 앱을 한 번 열어보세요 |
| 알림이 안 옴 | `bash ~/biotrial/fix.sh` |
| 알림은 오는데 배너가 아님 | 설정 → 알림 → Termux → 알림 표시 방식 → `팝업` 켜기 |

## 보안 — 해킹 위험은?

### 핵심: 외부에서 접속할 수 없습니다

서버가 **`127.0.0.1`(폰 자기 자신)에만** 열립니다.

```
uvicorn --host 127.0.0.1 --port 8000
         ↑ 이것이 전부입니다
```

같은 와이파이에 있는 사람도, 인터넷의 누구도 이 주소에 닿을 수 없습니다.
**외부에서 들어올 문이 아예 없습니다.** 그래서 비밀번호도 필요 없습니다.

통신은 **나가는 방향만** 있습니다.

```
폰  ──HTTPS──▶  ClinicalTrials.gov  (미국 정부)
    ──HTTPS──▶  opendart.fss.or.kr  (금융감독원)
```

둘 다 공개 데이터를 읽기만 하며, 폰의 정보를 보내지 않습니다.

### 점검한 것

| 항목 | 결과 |
|---|---|
| 외부 접속 경로 | 없음 (localhost 전용) |
| 화면에 원본 HTML 삽입 (XSS) | 없음 — React 가 전부 문자로 처리 |
| `eval` / `exec` / 셸 실행 | 없음 |
| XML 파서 (XXE) | 사용 안 함 — 정규식으로 태그만 제거 |
| 인증키 로그 노출 | 차단함 |
| 파이썬 패키지 | 버전 고정 |

### 실제로 하나 찾아서 고쳤습니다

알림 버튼에 들어가는 주소는 Termux 가 **셸 명령으로 실행**합니다.
주소 안의 등록번호는 외부 API 에서 오는 값이라, 만약 이상한 값이 섞여 오면
의도하지 않은 명령이 실행될 수 있었습니다.

```
https://clinicaltrials.gov/study/NCT1; rm -rf ~
                                     ↑ 이런 것
```

→ **허용된 주소 형태인지 검사**하고 **따옴표로 감싸도록** 고쳤습니다.
`clinicaltrials.gov`, `dart.fss.or.kr`, `fda.gov` 로 시작하는 정상 주소만 통과합니다.
비슷해 보이는 `clinicaltrials.gov.evil.com` 같은 주소도 막습니다.
(`tests/test_notify_security.py` 17개로 고정)

### 남는 위험과 대처

| 위험 | 실제 영향 | 대처 |
|---|---|---|
| **가짜 Termux 설치** | 가장 큰 위험 | 반드시 `github.com/termux` 또는 F-Droid 에서만 받으세요. 검색 결과의 다른 사이트는 쓰지 마세요 |
| **DART 인증키 유출** | 낮음 — 공개 데이터 조회용이라 남이 써도 조회량만 소모 | zip 을 남에게 보내지 마세요. 걱정되면 DART 에서 재발급하면 됩니다 |
| **폰 분실** | 낮음 — 저장된 건 공개 정보뿐 | 폰 잠금만 걸려 있으면 됩니다 |
| **Termux 자체의 권한** | 터미널이라 무엇이든 실행 가능 | 출처를 모르는 명령어를 Termux 에 붙여넣지 마세요 |

> 요약하면, **이 앱 때문에 폰이 해킹될 경로는 없습니다.**
> 주의하실 것은 오직 **Termux 를 공식 출처에서 받는 것** 하나입니다.
