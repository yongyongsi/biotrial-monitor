Termux 앱 2개 설치

폰에서

폰 브라우저로 아래 두 곳에 들어가, 각각 최신 릴리스의 arm64-v8a APK 파일을 받아 설치합니다.

1. github.com/termux/termux-app/releases — 리눅스 본체 2. github.com/termux/termux-api/releases — 알림과 자동 수집

파일 이름은 termux-app_v0.118…-arm64-v8a.apk 형태입니다. 설치 중 “출처를 알 수 없는 앱” 허용을 물어보면 허용해 주세요.

플레이스토어의 Termux 는 쓰지 마세요. 업데이트가 멈춰 있어 동작하지 않습니다.

두 앱은 반드시 같은 곳에서 받아야 합니다. 하나는 GitHub, 하나는 F-Droid 에서 받으면 서로 인식하지 못합니다. (F-Droid 를 쓰신다면 둘 다 F-Droid 에서)

안드로이드는 보안상 한 앱이 다른 앱의 알림 권한을 대신 가질 수 없습니다. 그래서 2개가 최소이며, 이보다 줄일 수는 없습니다.

배터리 설정 바꾸기

폰 · 설정 — 가장 중요

이 단계를 빠뜨리면 몇 분 뒤 수집이 멈춥니다. 삼성 폰은 배터리를 아끼려고 앱을 강제 종료하기 때문입니다. 설치 실패 원인 1위입니다.

① 설정 → 배터리 → 백그라운드 사용량 제한 → 절전 앱 / 딥 슬리핑 앱 목록에 Termux 가 있으면 빼주세요 ② 설정 → 애플리케이션 → Termux → 배터리 → 제한 없음

이 앱은 하루에 CPU 를 6초 쓰고 데이터를 0.8MB 씁니다. 배터리를 아끼려고 막아둘 이유가 없는 수준입니다.

같은 코드를 컴퓨터에서 실제로 측정한 값입니다.

메모리—70MB (볼 때만)
저장공간—설치 1GB · 데이터 연 2~3MB

외부에서 접속할 수 없습니다. 서버가 127.0.0.1(폰 자기 자신)에만 열립니다. 같은 와이파이에 있는 사람도, 인터넷의 누구도 닿을 수 없습니다. 통신은 나가는 방향만 있고 대상은 ClinicalTrials.gov 와 금융감독원 DART 뿐입니다.

주의할 것은 하나입니다. Termux 는 반드시 github.com/termux 또는 F-Droid 에서만 받으세요. 검색 결과에 나오는 다른 사이트의 APK 는 쓰지 마세요.

그리고 출처를 모르는 명령어를 Termux 에 붙여넣지 마세요. 터미널이라 무엇이든 실행됩니다.
