# 이메일 알림 켜기

앱을 열지 않아도 **중요한 변화가 생기면 메일이 옵니다.**
폰에 설치할 것은 없습니다. 이미 있는 메일 앱이 알려줍니다.

```
🔴 페니트리움 임상시험 승인                      ← 메일 제목
페니트리움 고형암 임상 2a상 임상시험계획이
미국 FDA 승인을 받았습니다
승인기관: 미국 FDA · 등록번호: IND 183600
```

기본값은 **🔴 매우 중요 / 🟠 중요** 만 보냅니다. 하루에 몇 통 오지 않습니다.

---

## 1. 지메일 '앱 비밀번호' 받기 (5분)

> 평소 쓰는 로그인 비밀번호가 **아닙니다.** 프로그램 전용으로 따로 발급받는 16자리입니다.
> 유출돼도 메일 보내기 외에는 못 하고, 언제든 취소할 수 있습니다.

1. https://myaccount.google.com/security 접속
2. **2단계 인증**을 켭니다 (이미 켜져 있으면 넘어갑니다)
3. 같은 화면에서 **앱 비밀번호** 를 찾아 들어갑니다
   - 안 보이면 주소창에 직접: https://myaccount.google.com/apppasswords
4. 이름은 아무거나 (예: `임상모니터`) 적고 **만들기**
5. **16자리**가 나옵니다. 띄어쓰기는 빼고 적어두세요

### 네이버·다음을 쓰신다면

- **네이버**: 메일 → 환경설정 → POP3/IMAP 설정 → **IMAP/SMTP 사용함**
  비밀번호는 네이버 로그인 비밀번호를 그대로 씁니다.
- **다음/한메일**: 메일 → 환경설정 → IMAP/SMTP 사용 설정

## 2. GitHub 에 넣기

저장소 → **Settings** → 왼쪽 **Secrets and variables** → **Actions** → **New repository secret**

세 개를 각각 추가합니다.

| 이름 | 값 |
|---|---|
| `EMAIL_USER` | 보내는 메일 주소 (예: `hong@gmail.com`) |
| `EMAIL_PASSWORD` | 1번에서 받은 **앱 비밀번호 16자리** |
| `EMAIL_TO` | 받을 주소 — 보내는 주소와 같아도 됩니다 |

> 여러 명이 받으려면 `EMAIL_TO` 에 쉼표로: `아빠@gmail.com,나@gmail.com`
>
> 넣은 값은 GitHub 안에서도 다시 볼 수 없습니다. 코드나 공개 파일에 들어가지 않습니다.

---

## 3. 확인

저장소 → **Actions** → **임상시험·공시 수집** → **Run workflow**

실행이 끝나고 **새로운 변화가 있으면** 메일이 옵니다.
변화가 없으면 메일도 오지 않습니다 (정상입니다).

---

## 집 컴퓨터나 폰에서 돌릴 때

`.env` 파일에 같은 값을 넣으면 됩니다.

```ini
EMAIL_USER=hong@gmail.com
EMAIL_PASSWORD=앱비밀번호16자리
EMAIL_TO=hong@gmail.com
```

## 언제 메일이 오나

| 등급 | 예 | 기본 |
|---|---|---|
| 🔴 매우 중요 | FDA 승인, 임상 중단, 결과 발표 | **옴** |
| 🟠 중요 | 임상 단계·상태 변경, 승인 신청, 기관 추가 | **옴** |
| 🟡 참고 | 학회 발표, 논문 | 안 옴 |
| ⚪ 일반 | 유상증자, 정기보고서 | 안 옴 |

전부 받고 싶으시면 저장소 → Settings → Secrets and variables → **Variables** 탭에서
`ALERT_MIN_SEVERITY` 를 `MEDIUM` 또는 `LOW` 로 만드세요.

---

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 메일이 안 옴 | 새로운 변화가 없으면 원래 안 옵니다. Actions 기록에서 `알림 N건 발송` 을 확인하세요 |
| `로그인 실패` | 로그인 비밀번호를 넣으셨을 수 있습니다. **앱 비밀번호 16자리**여야 합니다 |
| 앱 비밀번호 메뉴가 없음 | 2단계 인증을 먼저 켜야 나타납니다 |
| 스팸함으로 감 | 첫 메일을 '스팸 아님' 으로 표시해 주세요 |
